Where it lives

A Web Server DAT inside the TdHttpApi COMP. All route code is one Python file (td_http_api.py), embedded in the .tox, so it drops into any project.

Looking

  • /network structure, wires and references
  • /snapshot any node as an image, /sample pixel numbers
  • /errors with GLSL compile logs
  • /par, /opinfo real parameter names

Changing

  • /build many nodes, params and wires in one call
  • /par one or many parameters
  • /dat?mode=edit exact text edits
  • /run any Python, as a last resort

Several apps

Each TD app with this bridge takes the next free port from 3031 to 3040. The bar at the top shows the others it can find; give each one an App Label on the COMP.

Long jobs

Things that take several frames (non-TOP snapshots, frame grids, CHOP recordings) run in the background and are collected with /job, so TD never freezes.
